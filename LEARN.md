# 🏛️ Olympus Security Academy — Percorso didattico

Questo repository ospita **due cose complementari**:

1. **La piattaforma Olympus** — il tooling di sicurezza (CLI, moduli `src/olympus/…`). Vedi
   [`README.md`](README.md).
2. **Olympus Security Academy** — un **percorso formativo** di Ethical Hacking e Penetration
   Testing, strutturato per fasi (Reconnaissance → Vulnerability Analysis → Exploitation →
   Post-Exploitation), che usa i tool reali della piattaforma e il range locale `labs/mars`.

👉 **Inizia da qui:** [`academy/README.md`](academy/README.md)

- Prepara il lab: [`academy/00_Getting_Started/00_Setup_Lab.md`](academy/00_Getting_Started/00_Setup_Lab.md)
- Regole etiche/legali: [`academy/00_Getting_Started/01_Ethics_and_Legal.md`](academy/00_Getting_Started/01_Ethics_and_Legal.md)

> ⚖️ **Solo scopo educativo.** Le tecniche vanno usate esclusivamente su sistemi propri o
> autorizzati per iscritto. L'uso non autorizzato è illegale.

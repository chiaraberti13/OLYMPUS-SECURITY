Argus Certificate Transparency workbench

Extract in-domain subdomains from a Certificate Transparency export, offline. Paste the exact JSON array returned by crt.sh (?output=json) for a domain and this page parses it locally with the same core as olympus argus ct. No Certificate Transparency query is issued from here — only names that are a subdomain of the given domain and are conservative ASCII DNS hostnames are returned, deduplicated and sorted.

Educational, training and research use only, on domains you own or are explicitly authorized to assess. Passive OSINT parsing of data you provide; no network access.

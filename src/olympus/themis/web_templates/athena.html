Athena assessment planner

Build a validated, signable olympus.athena.plan from a named scan profile. A profile chooses which registered adapters run and with which safe limits; it carries no target of its own. Plan-building is local, deterministic and network-free: this page produces a plan document — it never executes a scan. Run a generated plan with olympus athena run.

Educational, training and research use only, on systems you own or are explicitly authorized to assess. A plan is marked authorized only on your explicit confirmation; it never self-authorizes a run.

Correlation workbench

Correlate a set of findings offline with the same core as olympus vulcan correlate and the API. Paste a JSON array of olympus.finding objects; this page derives the relationships between them — no scan and no network access.

A correlation is a relationship, not proof of compromise. Each one shows its epistemic class, so its strength is explicit: deterministic_result (a provable join on identity), suggested_correlation (a lead), unverified_hypothesis (an inference to review). A hypothesis is never presented as a fact.

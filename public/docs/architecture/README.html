Rules

  1. Numbering. Take the next free number; never reuse or renumber one. File

name: adr-NNN-short-kebab-title.md.

  1. Immutability. Once Accepted, an ADR is not rewritten. A changed decision

gets a new ADR that marks the old one Superseded by ADR-NNN; typos and dated notes are fine.

  1. Status. Proposed → Accepted or Rejected; later Superseded or

Deprecated.

  1. Binding scope. ADRs are non-binding guidelines by default. Only the

security invariants an ADR lists explicitly are requirements.

  1. Traceability. Name the roadmap ID and add the ADR to the index above in

the same pull request.
